## 0. 双层视觉架构总览

### 0.1 设计哲学

> **"用户在'剧外'看到的是《入戏》品牌,用户在'剧中'看到的是那部剧的世界。"**

这套设计哲学解决了平台型产品的核心矛盾——**既要品牌识别,又要沉浸体验**。

### 0.2 双层架构图

```
┌─────────────────────────────────────────────────────────────┐
│  🎭 剧目主题层(Theme Layer · 每剧定制 · 30%视觉资产)      │
│  ┌─────────┬─────────┬─────────┬─────────┐                  │
│  │《三体》 │《长相思》│《庆余年》│《繁花》 │ ··· 可扩展      │
│  │CRT赛博 │玄幻水墨 │卷宗朱砂 │霓虹年代 │                  │
│  └─────────┴─────────┴─────────┴─────────┘                  │
├─────────────────────────────────────────────────────────────┤
│  🏛️ 平台品牌层(Brand Layer · 固定不变 · 70%视觉资产)     │
│  Logo / 字体 / 核心色板 / 通用组件 / 全局动效               │
│  · 档案感 · 知性 · 克制 · "故事的入口"                     │
└─────────────────────────────────────────────────────────────┘

         ↑↓ 与产品逻辑架构完全对应

┌─────────────────────────────────────────────────────────────┐
│  剧目配置层(Drama Configuration Layer · 每剧10-15人日)     │
├─────────────────────────────────────────────────────────────┤
│  通用引擎层(Universal Engine Layer · 一次开发跨剧复用)     │
└─────────────────────────────────────────────────────────────┘
```

### 0.3 双层归属原则


| 用户场景               | 归属层     | 视觉表现           |
| ------------------ | ------- | -------------- |
| 用户在"剧外"(选剧/档案/导航)  | 🏛️ 品牌层 | 中性、克制、档案感      |
| 用户进入"剧中"(观看/介入/分支) | 🎭 主题层  | 强烈匹配该剧氛围       |
| 双层切换的瞬间            | ⚡ 转场动效  | **产品仪式感的核心来源** |


### 0.4 设计落地的关键收益


| 维度     | 传统单层设计       | 《入戏》双层设计           |
| ------ | ------------ | ------------------ |
| 跨剧复用   | ❌ 每剧重做UI     | ✅ 70%视觉资产跨剧复用      |
| 品牌识别   | ❌ 每剧不同,无品牌印象 | ✅ 用户始终能认出"这是《入戏》"  |
| 沉浸感    | ⚠️ 牺牲沉浸求统一   | ✅ 进入剧中完全沉浸         |
| 接入新剧成本 | 60-80人日UI重做  | **10-15人日(只做主题层)** |
| 产品讲述故事 | 弱            | ✅ 与产品架构完美对应,易论证    |

## 1. 平台品牌层(固定)

> **角色**:产品的"门面、骨架、记忆点"。所有用户在"剧外"的交互。

### 1.1 品牌DNA

> **「档案室的庄重 × 介入瞬间的星火」**

一个文学性的、知性的、有"入口感"的视觉品牌。它不是任何一部剧,而是**所有故事的共同入口**。

### 1.2 品牌氛围词


| 维度      | 关键词                 |
| ------- | ------------------- |
| **主氛围** | 克制、知性、档案感、"故事的入口"   |
| **次氛围** | 微弱的星火、等待、好奇         |
| **避免**  | 鲜艳、卡通、过度装饰、任何剧目特定元素 |


### 1.3 品牌配色

#### 主色板


| 色彩        | HEX       | 用途              |
| --------- | --------- | --------------- |
| **深空黑**   | `#0A0A0F` | 主背景             |
| **档案灰**   | `#1A1A1F` | 卡片/容器背景         |
| **暖银白** ⭐ | `#E8E8E8` | 主文字(克制,不刺眼)     |
| **微光紫** ⭐ | `#8B7FB8` | 品牌强调色(罕用,出现即重要) |


#### 辅助色


| 色彩  | HEX       | 用途    |
| --- | --------- | ----- |
| 雾灰  | `#6B7280` | 次要文字  |
| 纸白  | `#F5F5F5` | 高对比文字 |
| 警示红 | `#EF4444` | 错误/危险 |
| 成功绿 | `#10B981` | 完成/验证 |


**关键设计决策**:品牌层**故意没有"主色"——它是中性的**,这样进入剧目时,主题层的色彩冲击才更强烈。

### 1.4 品牌字体


| 用途      | 字体                            | 备注      |
| ------- | ----------------------------- | ------- |
| Logo    | **思源宋体** Heavy + 一点书法墨色       | 体现"故事感" |
| 中文标题    | 思源黑体 Bold                     | 现代克制    |
| 中文正文    | 思源黑体 Regular                  | 行距1.6倍  |
| 英文/数据   | Inter Regular/Bold            | 平台数据    |
| **不引入** | ~~JetBrains Mono / Orbitron~~ | 这些属于主题层 |


### 1.5 品牌质感

**全局贯穿的视觉肌理**:

1. **微噪点纹理**:背景叠加纸质颗粒(透明度6-8%) — "档案纸"的感觉
2. **极克制的留白**:重要元素之间留出呼吸空间
3. **若隐若现的光标**:页面某处有等待输入的光标动效 — 暗示"等你介入"

**避免**:CRT扫描线、霓虹辉光、Glitch等(这些都属于主题层)

### 1.6 品牌动效语言


| 动效        | 描述                          | 应用                 |
| --------- | --------------------------- | ------------------ |
| **打字机文字** | 逐字浮现                        | Slogan / 标题 / 关键文案 |
| **慢淡入**   | 0.6-1.2s opacity动画          | 页面入场               |
| **微悬停**   | hover时轻微上浮(translateY -2px) | 卡片/按钮              |
| **光标闪烁**  | 1Hz                         | 输入框                |


**避免**:Glitch / RGB分离 / 数据流爆发(这些是主题层动效)

### 1.7 品牌层覆盖的页面


| 页面             | 品牌层占比                      |
| -------------- | -------------------------- |
| 首页(剧目选择)       | 100% 🏛️                   |
| 剧目详情页          | 70% 🏛️ + 30% 🎭(顶图banner) |
| 印记档案页          | 100% 🏛️                   |
| 全局组件(按钮/输入/弹窗) | 100% 🏛️                   |
| 加载/错误/空状态      | 100% 🏛️                   |

## 2. 剧目主题层(可变 ·《三体》示例)

> **角色**:让用户"进入剧的世界"。所有用户在"剧中"的沉浸交互。

> 本节以《三体》为完整示例,其他剧主题层见第4节快速对比。

### 2.1 《三体》主题DNA

> **「1971年红岸基地的CRT显示器 × 2026年赛博朋克霓虹」**

一个穿越时空的视觉冲撞——既是历史的、孤独的、紧迫的,也是未来的、科技的、史诗的。

### 2.2 《三体》氛围词


| 维度      | 关键词                 |
| ------- | ------------------- |
| **氛围词** | 神秘、史诗、紧迫、孤独、跨越光年    |
| **质感**  | 复古CRT、扫描线、胶片颗粒、霓虹光晕 |


### 2.3 《三体》主题配色(覆盖品牌层)


| 色彩         | HEX       | 用途                |
| ---------- | --------- | ----------------- |
| **CRT绿** ⭐ | `#39FF14` | 主文字/光标/CRT元素      |
| **琥珀光** ⭐  | `#FFB347` | 警告/重要提示/历史感       |
| **霓虹蓝**    | `#00D4FF` | 科技/AI元素/数据流       |
| **三体紫**    | `#9D4EDD` | 三体元素/未知           |
| **终端黑**    | `#0D1117` | CRT显示器背景(覆盖品牌深空黑) |


### 2.4 《三体》主题字体(在品牌字体上叠加)


| 用途        | 字体                 | 备注   |
| --------- | ------------------ | ---- |
| 等宽(CRT界面) | **JetBrains Mono** | 模拟终端 |
| 装饰数字      | **Orbitron**       | 科幻感  |
| 装饰显示      | Major Mono Display | 偶尔点缀 |


### 2.5 《三体》主题质感

**主题独有视觉肌理**:

1. **CRT扫描线**:全屏覆盖的细横线动画(透明度3-5%)
2. **胶片颗粒**:背景叠加噪点纹理(透明度8-12%)
3. **霓虹辉光**:关键元素发光边缘(box-shadow多层)
4. **数据流粒子**:背景缓慢浮动的小光点
5. **Glitch效果**:关键转场使用RGB色彩偏移

**示例代码**:

```css
/* CRT扫描线 */
background: linear-gradient(
  transparent 50%,
  rgba(57, 255, 20, 0.05) 50%
);
background-size: 100% 4px;

/* 霓虹辉光 */
box-shadow:
  0 0 5px #39FF14,
  0 0 15px #39FF14,
  0 0 30px rgba(57, 255, 20, 0.5);
```

## 3. 主题层配置变量清单

> **核心创新**:每部剧的主题层 = 一个**视觉配置文件**。换剧时只改配置,不改平台代码。

### 3.1 配置变量Schema

```yaml
drama_theme:
  # 基本信息
  drama_id: "santi"
  name: "《三体》"
  intervention_container: "三体游戏·拓展协议"
  
  # 主色板(覆盖品牌主色)
  palette:
    primary: "#39FF14"          # 主色,文字/边框
    accent: "#FFB347"            # 强调色,警告/提示
    secondary: "#00D4FF"         # 次强调色,数据/科技
    tertiary: "#9D4EDD"          # 第三色,特殊元素
    background_overlay: "#0D1117" # 背景覆盖色
  
  # 字体调味(在品牌字体上叠加)
  fonts:
    decorative: "JetBrains Mono"  # 等宽/终端字体
    display: "Orbitron"            # 装饰显示字体
    style_modifier: "monospace"    # 字体修饰风格
  
  # 视觉肌理
  textures:
    - id: "crt_scanlines"
      opacity: 0.05
      enabled: true
    - id: "film_grain"
      opacity: 0.10
      enabled: true
    - id: "neon_glow"
      enabled: true
  
  # 沉浸氛围
  ambience:
    background_element: "starfield_particles"  # 背景元素
    particle_density: "medium"                  # 粒子密度
    color_filter: "cool_dark"                   # 色调倾向
    
  # 关键转场动效
  transitions:
    enter_drama: "glitch_rgb_split"   # 进入剧中(品牌层→主题层)
    exit_drama: "fade_to_archive"     # 退出剧中(主题层→品牌层)
    page_transition: "data_flow"       # 主题层内页间转场
    
  # UI风格修饰
  ui_style:
    terminal_mode: true        # 是否启用终端模式
    typing_effect: true         # 是否启用打字机
    cursor_style: "blink"       # 光标样式
    border_style: "neon_glow"   # 边框样式
    
  # 关键页面隐喻
  metaphors:
    intervention_ui: "crt_terminal"      # 撰写页隐喻物
    judgment_ui: "radar_chart_neon"      # 评分页隐喻物
    branch_ui: "broadcast_signal"        # 分支页隐喻物
    
  # 音效(可选,Demo阶段不必做)
  audio:
    ambient: "low_hum_60hz"
    transition_sfx: "static_burst"
    typing_sfx: "mechanical_keys"
```

### 3.2 配置变量在Figma中的表达

在Figma中,把每个变量做成 **Local Variables**:

- 颜色 → Color Variables
- 字体 → Text Style Variables
- 间距 → Number Variables

切换主题时,**Variables Mode** 一键切换 → 整个UI随之变化。

> **Figma操作**:
>
> 1. 创建Variable Collection: `Drama Theme`
> 2. Modes: `Santi`, `Long-Xiang-Si`, `Qing-Yu-Nian`, `Fanhua`
> 3. 每个组件使用Variables引用,而非硬编码

**关键设计决策**:卡片框架是品牌层(中性),但封面图自然带有该剧的视觉信号——形成"克制底色上的色彩点"。

- Slogan打字机
- 卡片瀑布流浮现(每张延迟120ms)

#### 这是双层切换的视觉爆发点

2. 1.5-2.5s:身份徽章浮现(发光三体符号)
3. 2.5-3.5s:身份名打字机(Mono字体)
4. 3.5-5.0s:任务文字逐行浮现
5. 5.0s+:行动按钮(主题色脉冲)

**视觉规格**:

- 背景:终端黑 #0D1117(主题背景色)
- 主文字:CRT绿
- 副文字:琥珀光
- 装饰:扫描线密度加倍 + 数据粒子加速

**仪式音效(可选)**:CRT嗡鸣 + 低频心跳 + 信号传输声

### 6.2 双层切换转场设计 ⭐ 这是产品仪式感的核心

#### 转场1:进入剧目(品牌层 → 主题层)

**应用**:从剧目详情→剧集观看

**视觉时序(1.5秒)**:

1. 0-0.5s:当前页面整体淡出
2. 0.5-1.0s:屏幕短暂全黑
3. 1.0-1.5s:主题层视觉元素淡入(扫描线先出现,然后视频画面浮现)

**心理感受**:像走进电影院灯光熄灭的瞬间。

#### 转场2:UI唤起(主题层内深度切换)

**应用**:节点触发瞬间

**视觉时序(1.5秒)**:

1. 0-0.5s:Glitch RGB分离(画面"故障")
2. 0.5-1.0s:扫描线密度加倍,数据粒子爆发
3. 1.0-1.5s:画面变暗,身份徽章浮现

**心理感受**:像被"召唤"进入了故事。

#### 转场3:退出剧目(主题层 → 品牌层)

**应用**:从分支视频→印记档案

**视觉时序(1.0秒)**:

1. 0-0.4s:主题层元素优雅淡出
2. 0.4-0.8s:暖银白光从屏幕中心扩散
3. 0.8-1.0s:品牌层档案柜浮现

**心理感受**:像从一个梦中缓缓醒来。

### 6.3 转场动效在不同剧的变化


| 转场   | 《三体》       | 《长相思》 | 《庆余年》 | 《繁花》 |
| ---- | ---------- | ----- | ----- | ---- |
| 进入剧目 | Glitch RGB | 水墨晕染  | 卷轴展开  | 霓虹闪烁 |
| 退出剧目 | 信号衰减       | 雾气消散  | 卷轴收起  | 雨幕落下 |


→ **同一时刻发生同样的体验**(从平台切到剧中),但视觉表达完全不同——这就是主题层配置的力量。

### 10.2 Figma Variables 配置(关键!)

#### 创建Variable Collection

1. Figma → Local variables → Create collection
2. 命名:`Drama Theme`
3. 添加Modes:`Brand`(默认)、`Santi`、`Long-Xiang-Si`、`Qing-Yu-Nian`、`Fanhua`

#### 配置变量

```
颜色变量(每个mode填值):
- color/primary
- color/accent
- color/secondary
- color/background-overlay

字体变量:
- font/decorative
- font/display

数值变量:
- texture/scanline-opacity
- texture/grain-opacity
```

#### 应用变量
